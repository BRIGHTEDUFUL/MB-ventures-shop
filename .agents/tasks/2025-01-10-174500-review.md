## iOS zoom prevention: 16px input enforcement with label scoping

The 767px breakpoint adds explicit `label { font-size: 14px; }` and `label input, label select, label textarea { font-size: 16px; }` rules to prevent cascade inheritance from breaking the iOS zoom threshold. The global `label` rule is 14px, labels wrap inputs, and without the child re-declaration a label's font-size could cascade to the input and drop it below 16px. The existing `input, select, textarea { font-size: 16px; }` rule at <767px is now reinforced by the label-scoped override.

## 44px touch targets: auth-switch and auth-address-form

The 767px breakpoint adds `.auth-switch button { min-height: 44px; }` to cover the sign-in/sign-up toggle, "Forgot your password?" and "Back to sign in" links, all of which are `Button variant="link"` with no intrinsic height. The 480px breakpoint adds `.auth-address-form button { min-height: 44px; }` when the address form stacks.

The `/account` refactor groups these link buttons inside `<div className="auth-switch">`. The FieldError component wraps error messages in `.auth-error`, which reads as an intentional event rather than stray red text. The auth-note (redirect message) uses `.auth-note` with tinted background and icon glyph.

## Safe-area-inset-bottom: auth-page padding

The 480px breakpoint changes `.auth-page { padding-bottom: 48px; }` to `.auth-page { padding-bottom: calc(48px + env(safe-area-inset-bottom)); }`, ensuring breathing room between the form footer and the bottom nav on notched phones.

## 360px breakpoint: extreme-narrow fit

The new `@media (max-width: 360px)` block reduces horizontal padding in `.auth-panel` (28/20px → 24/16px) and `.auth-brand` (16/18px → 14/16px), scales the lockup image (48×44px → 42×38px), shrinks the title (30px → 28px), and drops the card's border-radius (24px → 18px). At 320px viewport width, 16px padding leaves 288px content width. The smaller border-radius reduces clipping risk at narrow widths.

## Account refactor: AuthFrame wrapper and semantic classes

The `/account` route now wraps all flows in `<AuthFrame>`, which renders the glass card, photo panel with shop wordmark and facts, and the form column. The four flows (sign-in/sign-up, forgot password, reset password, signed-in account) each return an `<AuthFrame>` with flow-specific title/lead and form children. Error messages move from `<p className="text-sm text-destructive">` to `<FieldError>`, which renders `.auth-error` with icon glyph. The redirect notice moves to `.auth-note`. Link buttons group in `.auth-switch`, orders render in `.auth-orders`, the address form uses `.auth-address-form`. The loading state shows a centered logo and message in `.auth-loading`.

The refactor eliminates direct DOM structure (no more `<div className="page-content wrap"><h1 className="page-title">…`), replacing it with the AuthFrame's branded shell while preserving the existing auth logic (state management, form submission handlers, Convex mutations).

## Glass aesthetic and oklch preservation

The auth-brand photo overlay uses two layers: a flat 32% shade for consistent readability, then a gradient (55% → 88%) deepening toward the copy at the bottom. The auth-note and auth-error backgrounds use `color-mix(in oklch, …)` to derive tinted fills from semantic colors. The auth-lockup logo box-shadow is a white ring (`0 0 0 3px rgb(255 255 255 / 22%)`), not oklch — the one exception in the new CSS, likely because the white ring is a photo-overlay detail that doesn't need theme support.

## Breakpoint hierarchy

The final hierarchy: 1600px (hero centering, storefront polish), 1100px (auth-card 440px/1fr → 360px/1fr), 1023px (storefront adjustments), 900px (auth-brand collapses from side panel to top band), 767px (mobile touch rules, storefront mobile layout, iOS zoom prevention, auth-switch tap targets), 480px (auth fine-tuning, safe-area-inset, auth-address-form button), 360px (extreme narrow, tighter padding, smaller lockup/title, reduced border-radius). No conflicting rules detected across breakpoints — each refines or overrides the prior without introducing contradictions.
